# Sales Data Analysis Project

## 📊 Project Overview
This project demonstrates data cleaning and analysis on a messy sales dataset.

## 🧹 Data Cleaning Steps
- Removed duplicates
- Handled missing values
- Fixed data types
- Standardized date format
- Removed invalid data
- Recalculated Total column

## 📈 Analysis
- Sales by Product
- Sales by Category
- Sales trends over time

## 📁 Files
- messy_sales_10k.csv (raw data)
- cleaned_sales_data.xlsx (clean data)

## 🛠 Tools Used
- Excel
